## Περιγραφή έργου
Αυτό το αποθετήριο περιέχει ένα σενάριο (script) σε Python που πραγματοποιεί συγκριτικό έλεγχο απόδοσης (benchmark) μεταξύ της παραδοσιακής, μονοπύρηνης επεξεργασίας κειμένου (Single-Node Python MapReduce) και της κατανεμημένης επεξεργασίας δεδομένων με χρήση Apache Spark RDDs (PySpark). Ο κώδικας παράγει αυτόματα ένα μεγάλο αρχείο δεδομένων κειμένου txt (input_text.txt) μεγέθους 125MG, εκτελεί και τις δύο μεθόδους, μετράει τους χρόνους εκτέλεσης και εξάγει αυτόματα ένα γραφικό διάγραμμα σύγκρισης (spark_vs_python_benchmark.png).
